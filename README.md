## User stories

1. A bank customer should be able to deposit into an existing account. (Shook)
2. A bank customer should be able to withdraw from an account. 
3. A bank customer should be able to check their account balance for any account that they currently have. 
4. A bank customer should be able to view their transaction history for an account. 
5. A bank customer should be able to create an additional account with the bank. 
6. A bank customer should be able to close an existing account.
7. A bank customer should be able to transfer money from one account to another. 
8. A bank adminstrator should be able to collect fees from existing accounts when necessary.
9. A bank adminstrator should be able to add an interest payment to an existing account when necessary.

## What user stories do you intend to complete next iteration?
We want to extend functionality for our bank from one client and one administrator to being able to handle multiple clients. The user stories we thought would help us achieve this are:

1. A new bank customer should be able to register with the bank by creating a unique username and password.
2. An existing bank customer should be able to log in using their username and password.
3. A logged-in bank customer should be able to log out of their account.
4. A bank customer should be able to own multiple bank accounts under a single customer profile.
5. A bank customer should be able to view all bank accounts associated with their customer profile.
6. A bank customer should be able to switch between their bank accounts without logging out.
7. A bank customer should only be able to access and manage accounts associated with their customer profile.
8. A bank administrator should be able to view all registered customers and their associated bank accounts.

## Is there anything that you implemented but doesn't currently work?
All tests pass and we ran into no errors or unexpected behavior when interacting with the current state of the bank.

## What commands are needed to compile and run your code from the command line?
We would run 'bash runApp.sh' from the command line to compile and run our code. We included the Java compilation and execution commands within the runApp.sh file, so all we need to do is run it as a Bash script.
